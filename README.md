🎯 Project Objective

The main goal of this project was to build a real-world, responsive e-commerce application using the MERN stack and understand how frontend, backend, database, authentication, APIs, and deployment work together in a production-style application.

🛠️ Technologies & Tools Used

Frontend:

⚛️ React.js
🎨 Tailwind CSS
💠 Flowbite React
🧭 React Router
🎠 Swiper.js
🔥 Firebase Authentication
⚡ Vite
🎯 React Icons

Backend:

🟢 Node.js
🚂 Express.js
🍃 MongoDB
🔗 REST APIs

Authentication & Security:

🔥 Firebase Authentication
🔐 Protected Routes
👤 User Authentication & Authorization
